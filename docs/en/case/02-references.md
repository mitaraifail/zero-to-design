## User Notes

### Reference 1: Notion
- **Overall impression**: Very calm; whitespace and text hierarchy feel good. But worried it may be too airy for a data dashboard; density could be higher.
- **Takeaways**: calmness, text hierarchy, whitespace rhythm.
- **Avoid**: too empty for a data dashboard, insufficient density.
- **Extractable elements**: layered typography, restrained card spacing.

### Reference 2: Kinfolk
- **Overall impression**: Love the calm brought by low saturation and generous whitespace, but the magazine feel is too strong for a SaaS backend.
- **Takeaways**: low saturation, calmness, generous whitespace.
- **Avoid**: overly editorial magazine feel, unsuitable for a tool backend.
- **Extractable elements**: low-saturation color usage, gentle page rhythm.

### Reference 3: Aesop
- **Overall impression**: Warmth within restraint is great; colors are layered without noise. But the premium feel leans luxurious; an indie-developer tool should be more approachable.
- **Takeaways**: warmth within restraint, layered colors, quietness.
- **Avoid**: too luxurious/premium, distant from indie developers.
- **Extractable elements**: warm-but-quiet color logic.

### Reference 4: Monocle
- **Overall impression**: Favorite. Editorial feel + information density is well balanced; restrained but readable. Exactly the "order within calm" Pulse wants.
- **Takeaways**: editorial feel, information density, readability, order within restraint.
- **Avoid**: no obvious negatives.
- **Extractable elements**: balance of density and whitespace, editorial layout, ordered but not cold reading rhythm.

## Extracted Design Clues

- **Overall mood tendency**: order within calm, restrained but readable, editorial, approachable but not cheap, professional but not cold.
- **Color tendency**: light mode; low-saturation, warm-neutral base; no purple, no blue as primary, no gradients; consider warm gray, off-white, soft earth tones, or muted green/ochre as accents.
- **Typography tendency**: clear readable sans-serif as the base; Display can carry a hint of human/editorial tone; emphasize hierarchy over decoration.
- **Layout tendency**: denser than Notion, lighter than dense enterprise dashboards; card-based organization; key numbers first; whitespace with rhythm but not empty.
- **Hard no**: default dark theme, purple primary, blue primary, gradient backgrounds, overly magazine-like, overly luxurious.
