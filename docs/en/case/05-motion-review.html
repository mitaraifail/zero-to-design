Easing Curves

All motion uses the same natural deceleration curve
ease-out (recommended)
cubic-bezier
(0.25, 1, 0.5, 1) · Natural deceleration, fast then slow
Used for hover, entrance, and press. The only easing in Pulse.
bounce (disabled)
cubic-bezier
(0.34, 1.56, 0.64, 1) · Bounce effect, disabled
Bounce / elastic feels dated and distracting. Not used in Pulse.

Motion Specs

Scenario Duration Easing Properties

Press feedback 150ms cubic-bezier(0.25, 1, 0.5, 1) transform: scale(0.97)
Entrance animation 350–500ms cubic-bezier(0.25, 1, 0.5, 1) transform, opacity
Arrow micro-shift 200ms cubic-bezier(0.25, 1, 0.5, 1) transform: translateX(3px)
Hairline draw 800ms cubic-bezier(0.25, 1, 0.5, 1) transform: scaleX / scaleY
Reduce motion 0.01ms linear All animations forced off

All motion above follows: animate only transform and opacity; do not block interaction; respect prefers-reduced-motion.
